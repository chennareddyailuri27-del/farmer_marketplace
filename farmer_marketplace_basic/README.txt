FARMER MARKETPLACE - BASIC VS CODE PROJECT

WHAT IS INCLUDED
- Product marketplace with sample farm produce
- Search products by name or farmer
- Add products to the cart and change quantities
- Add/list produce using the farmer form
- Demo checkout (does not take payment)
- Products and cart are saved in your browser using localStorage

HOW TO RUN IN VS CODE (WINDOWS)
1. Download and extract farmer_marketplace_basic.zip.
2. Open Visual Studio Code.
3. Select File > Open Folder.
4. Choose the extracted folder named farmer_marketplace_basic.
5. In the left Explorer panel, click index.html.
6. Easiest option: install the "Live Server" extension:
   - Click Extensions on the left (four-square icon).
   - Search for "Live Server" by Ritwick Dey and install it.
   - Right-click index.html and select "Open with Live Server".
7. Your browser should open the Farmer Marketplace website.

ALTERNATIVE WITHOUT LIVE SERVER
- Open the extracted folder in File Explorer.
- Double-click index.html to open it in your browser.

IMPORTANT
- This is a beginner-friendly front-end demo. It does not need Python, Node.js, or MongoDB.
- Product listings and cart data are saved in the current browser only.
- Login, secure accounts, a shared database, and real payments are not included.
- If you clear browser storage, the saved demo listings and cart may be removed.
